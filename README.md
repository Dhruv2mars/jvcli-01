# jvcli-01

Javelin CLI. Local agent-native version control for humans and agents.

One World. Isolated sparse Layers. Automatic checkpoints. Native agent context. Stack. Atomic Publish.

## Status

Implementation of the Javelin `javelin-cli` specification, revision 1.0, built with Effect TypeScript. Executable name is `jvcli`.

## Quick start

```sh
bun install
bun run build
node dist/cli-entry.js init my-repo
node dist/cli-entry.js status
node dist/cli-entry.js --help
```
